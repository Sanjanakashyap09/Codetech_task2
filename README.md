# 📈 Predictive Modeling with Linear Regression

## Objective

The objective of this project is to develop and evaluate a **Linear Regression** model for predicting a continuous target variable using synthetic data.

The project includes:

* Generating a synthetic dataset with a single input feature and a continuous target variable.
* Splitting the dataset into training and testing sets.
* Training a Linear Regression model.
* Evaluating the model using **Mean Squared Error (MSE)** and **R-squared (R² Score)**.
* Visualizing the regression line and comparing predicted values with actual values.

---

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

---

## Model Evaluation

The model was evaluated using the following performance metrics:

* **Mean Squared Error (MSE)**
* **R-squared (R² Score)**

These metrics measure the prediction accuracy and how well the model explains the variance in the target variable.

---

# Conclusion

The Linear Regression model demonstrated good performance in predicting the continuous target variable from the synthetic dataset. The evaluation metrics indicate that the model successfully captured the relationship between the input feature and the target variable.

### Key Findings

#### 1. Training Performance

* Achieved a **low Mean Squared Error (MSE)**.
* Obtained a **high R² score**, indicating that the model explains a significant portion of the variance in the target variable.

#### 2. Testing Performance

* The testing dataset produced a slightly higher MSE and a slightly lower R² score than the training dataset.
* This suggests that the model generalizes reasonably well to unseen data, with some scope for further improvement.

#### 3. Regression Line

* The regression line closely follows the overall trend of the data.
* Most data points lie near the regression line, indicating a strong linear relationship between the feature and the target.

#### 4. Residual Analysis

* The residuals are randomly distributed around zero without any noticeable pattern.
* This indicates that the model does not exhibit significant systematic bias.
* A few outliers are present, which may slightly affect prediction accuracy.
